# MAP-001: Clickable hex island mock-up

Status: Done

## Approval and scope

Approved in conversation on 2026-11-04: hex tiles, a fixed irregular island,
simple terrain visuals, and a clickable mock-up before gameplay.

- Replace the empty canvas with a compact fixed hex board.
- Surround connected land with non-playable water.
- Show plains, forest, and mountains using colors and letter markers.
- Select tiles with the left mouse button and display coordinates and terrain.
- Fit the board and information readout at the supported minimum window size.
- Keep map data separate from presentation.

No ownership, economy, terrain bonuses, armies, procedural generation, or
turn rules. Selecting water inspects it; it does not make it playable.
Terrain placement is illustrative, not a balanced gameplay map.

## Acceptance criteria

- Fixed irregular land outline with connected land and visible surrounding water.
- Hex centers select the corresponding tile; clicking outside tiles does nothing.
- Selection and terrain readout remain consistent after resizing.
- Headless checks and Linux graphical validation pass.

## Verification

- Godot 4.7.2 headless project import passed without errors.
- Headless map smoke checks passed: 81 total hexes, 35 land hexes, deterministic
  terrain, all four terrain types, connected land, and surrounding water margin.
- Viewport-routed clicks selected every hex correctly and updated the terrain
  readout at requested window sizes of 1280 x 800 and 800 x 600.
- All hex polygons and UI elements fit their bounds; outside clicks preserved
  selection.
- The same checks passed with the Linux graphical Compatibility renderer.
- Captured and visually inspected the rendered board, selection outline, legend,
  and information readout.
- The test game closed cleanly. Windows was not tested.
