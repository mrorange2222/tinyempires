# MAP-004: Empty grassland tiles and non-clickable water

Status: Done

## Approval and scope

Requested in conversation on 2026-11-04: make unplayable water non-clickable
and beautify the default empty land tile before adding objects.

- Use empty plains across the existing island; defer forest/mountain placement.
- Add deterministic grass texture, gentle color variation, subtle tile edges,
  and earthy coastline sides without props, letters, or external assets.
- Ignore water clicks without changing selection/readout or emitting selection.
- Preserve scrolling, tilt, tile size, and selectable land/coastline faces.

- Headless checks and Linux graphical validation pass.
